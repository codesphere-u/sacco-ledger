# sacco-ledger

**Offline-first VSLA & SACCO cooperative member share-capital, M-of-N officer quorum loan approval, integer minor-unit amortization, end-of-cycle share-out dividend calculator, and tamper-evident SHA-256 passbook engine.**

Zero runtime dependencies. Pure Python 3.11+ & SQLite WAL. Replaces tamper-prone paper passbooks and fragile spreadsheets for grassroots Village Savings and Loan Associations (VSLAs) and SACCOs.

## Quick Start

```bash
uv sync --extra dev
sacco-ledger demo
```
