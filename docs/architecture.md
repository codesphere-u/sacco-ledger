# Architecture — `sacco-ledger`

- `sacco_ledger.ledger`: Integer minor-unit amortization calculator, SQLite WAL member/loan/approval schema, M-of-N officer quorum enforcement with anti-self-approval checks, GSM-7 `<=160`-char SMS receipts, pro-rata VSLA share-out dividend engine, and SHA-256 hash-chained passbook verifier.
- `sacco_ledger.cli`: Full savings-to-share-out simulation CLI.
